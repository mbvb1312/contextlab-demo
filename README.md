# ContextLab public demonstration

Public frontend for the English-to-Tamil story localization research project.
The home page uses the same story workspace as the local CUDA application.

Choose **View recorded GPU run** to inspect an actual controlled execution of
MiniLM retrieval, Qwen3 context resolution and OPUS-MT translation. Its output
is unmodified, labelled as recorded, and requires human Tamil review.

Fresh cloud inference is **not connected**. The recording does not run models
or translate arbitrary inputs. The older dashboard is at `research.html`.

Only public website assets are exported here. This repository does not contain
private uploaded stories, local model caches, account tokens or training data.
